# Next milestone: ordinary setup for an unfamiliar real plug-in

## Goal

A musician installs and authorizes an unfamiliar owned Arturia plug-in through
managed ASC on the Deck, prepares it through the manager, then plays/saves/reopens
it in a native Linux DAW. Shared defaults, profiles and capabilities should make
the first attempt work. Qualification records evidence; it is not per-plug-in
permission or a separate build.
