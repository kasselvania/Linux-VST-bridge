## Owner and action boundary

Serum is a product installed into the FL workspace. Its selected installer,
active installation operation, append-only result history, installed Windows
VST3 module and bundle root are separate from the FL application selection,
current installed executable, and installation/uninstall histories. The
manager offers exact typed selection, install, and finish-install actions in
Workspaces. Selection verifies the admitted artifact but executes no Windows
code. Installation uses the existing supervised installer cohort in the same
prefix and runner. The operator handles lawful vendor UI and activation.

The manager does not claim an arbitrary VST3 found in the prefix. Existing
Serum files without matching product authority block installation. Installer
exit, module discovery, FL scan, audio, automation, export, and fresh-session
use are separate observations. A nonzero installer exit with a discovered
module remains `needs_user_action`; it is not silently called a clean install.

The native Bitwig bridge retains its six publications and separate Serum
candidate-D environment. No Linux proxy, bridge transport, native publication,
DSP lease, or six-instance capacity claim is created by direct FL hosting.

installer and native publications. Keep the present prefix, user roots, runner,
