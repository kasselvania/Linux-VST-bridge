# Focused design review (when needed)

```text
Review whether the proposed behavior solves the user's actual problem.
Check consequential API, lifetime, thread, failure and data-protection choices
against relevant sources and current code. Identify concrete gaps and the
smallest repair. Do not prescribe every private type or require a new
framework. Distinguish an unresolved design decision from normal engineering
latitude. Do not edit, merge or run a fixture unless separately authorized.
```
