What this flow needs to establish


The five agreed choices
    

  1. First installation: automatic availability for chosen plug-ins after vendor steps and checks. Changing a working setup gets its own consequence review.
    2. 

  2. Existing collections: managed installations for beta, with safe coexistence. Migration from external Wine/yabridge setups comes later.
    3. 

  3. Storage: drive choice, library reconnection and supported same-machine moves in beta. Full collection backup and computer transfer come later; update recovery remains required.
    4. 

  4. Completion: observed facts drive normal status. Feedback is optional in help/testing; no “mark installed” chore.
    5. 

  5. Support: direct private contact with the maintainer and deliberate diagnostic export/sharing. No in-app support submission requirement.
    6. 

These policy choices are selected. The flow details still need walkthrough and usability validation. Boxes describe work, not screens; diamonds include automatic product decisions, not just user prompts.
