# MF3 implementation and installed readback

The manager now separates discovered classes, preliminary inspection, immutable
preparation, experimental publication, attributed evidence, explicit review and
ordinary publication. The instrument and effect remain separate products.

The source-owned Windows fixture provided an actual component/controller
association and completed inspection. The production preparation/build owner
then built its native proxy on the Deck, retained the descriptor and native
identities, reused the exact candidate, enabled and removed a private fixture
publication, and refused ordinary publication without qualification. Loading
that native artifact verified its exported processor/controller class identities.
No commercial plug-in or audio session was involved. The first harness attempt
refused its non-private test directory before building; the harness permission
repair and subsequent passing run are retained separately.

Immutable installation changed the manager/frontend and added the fixed
preparation kit. The default Windows host, supervisor, native product artifacts
and current publications were preserved. Readback adopted the retained SV1
Serum candidate without reinstallation, rescan, reinspection, rebuild or
republication. Its original editor/gesture observations and later failure retain
their original provenance. Serum is prepared, unpublished and unqualified;
Serum FX remains separately installed-unqualified. Missing historical controller
and editor-interface metadata is explicitly unavailable.

Installation occurred with both user applications closed and zero DSP or
maintenance ownership. The service and two keepers were restored; no lease,
transaction, stale transport or capture arm remains. 243 retained records/artifact
files and five protected projects matched their entry hashes. Generated unit and
process owners retired. The operator opened the new manager and reported seeing Serum's experimental-use
control. Subsequent canonical readback confirmed this is the offered Enable
button: Serum remained prepared/unpublished, zero DSP leases, and ordinary
publication unavailable. No click, qualification decision or runtime result was
inferred from that observation.

See `result.json` for exact source, artifact identities, validation runs, original
provenance and nonclaims. This is an implementation for independent review,
not acceptance of Serum's compatibility or authorization to merge either PR.
